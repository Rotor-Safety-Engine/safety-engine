# 常见问题 (FAQ)

## 基础问题

### Q: Safety Engine 和 VLA 模型是什么关系？

Safety Engine 是 VLA 模型的**物理安全守门员**。VLA 负责理解意图、规划动作，Safety Engine 负责在动作执行前校验物理安全性。两者互补不重叠。

### Q: 支持哪些编程语言？

社区版目前提供 Python 实现。C++ / Rust 版本在路线图中。
由于核心是纯数学计算，移植到其他语言非常直接。

### Q: 可以在边缘设备上运行吗？

可以。纯标准库实现，零依赖，内存占用 <5MB，可直接部署到 ARM / x86 边缘设备。

## 技术问题

### Q: 判定结果可以修改吗？

可以。所有安全阈值都可以通过 `robot_data` 或扩展对象库来调整。引擎提供了 `recommended_params` 智能推荐安全参数。

### Q: 支持连续动作轨迹吗？

当前版本支持单动作瞬时判定。连续轨迹校验在路线图中，可通过逐帧调用作为临时方案。

### Q: 为什么没有用神经网络？

物理安全判定要求 100% 可解释、零幻觉。纯确定性物理计算在可解释性和性能上都优于神经网络方案。

## 企业版问题

### Q: 社区版和企业版有什么区别？

详见 README 中的版本对比表。核心区别是企业版提供 Layer 5 力学增强层，包括：
- 作用-反作用完整对（3D向量）
- 动量-冲量-时间链路分析
- 能量守恒校验
- 旋转矩阵方向向量支持
- 纯函数力学分析接口
